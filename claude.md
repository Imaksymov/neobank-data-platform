# NeoBank Data Platform

Учебная платформа данных розничного банка на синтетических данных.
Имитирует продакшн-контур: OLTP-источник → озеро (Parquet/MinIO) →
хранилище → витрины → BI. Автор — SQL-разработчик из банка,
осваивает современный дата-стек.

## Команды

- `make up` / `make down` — окружение (Postgres, MinIO, Metabase)
- `make lint` — ruff + mypy
- `make test` — pytest
- `make psql` — консоль базы


## Правила, которые не проверяются автоматикой

- Денежные суммы — только `numeric`. Никогда `float`, включая
  промежуточные вычисления и тестовые данные.
- Время хранится в UTC. Конвертация — только на витринах.
- Слои строго односторонние: staging → intermediate → marts.
  Модель никогда не ссылается на более высокий слой.
- Staging не содержит бизнес-логики: только переименование,
  приведение типов, дедупликация.
- Именование моделей: `stg_<источник>__<сущность>`,
  `int_<описание>`, `fct_<факт>`, `dim_<измерение>`.

## Как со мной работать

- При неоднозначности в постановке задай уточняющий вопрос,
  не угадывай.
- Не добавляй сервисы, зависимости или файлы, которых я не просил.
- Меняй один слой за раз.
- Прежде чем писать тест, спроси, что я считаю корректным
  результатом.
